# Talk the Talk — landing page

Página estática (HTML + CSS inline), sem dependências além das fontes do Google Fonts.

## Rodar localmente
Opção 1: dê dois cliques em `index.html`.
Opção 2 (servidor local):
```
python3 -m http.server 8000
```
e abra http://localhost:8000

## Publicar no GitHub Pages
1. Crie um repositório e envie estes arquivos (`index.html`, `assets/`, `README.md`).
2. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O endereço ficará como `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
